# Security

MF StaffCore Lite keeps employee, attendance, leave, and payroll records in the WordPress database of the site where it is installed.

## Reporting a vulnerability

Report security issues privately through GitHub Security Advisories:

https://github.com/mehdifalahi/mf-staffcore-lite/security/advisories/new

Please do not file a public issue for an unpublished vulnerability. Do not attach a production database, payslips, or real employee records.

## Updates

Security fixes ship in the current Lite release on WordPress.org and in this repository.

https://wordpress.org/plugins/mf-staffcore-lite/
