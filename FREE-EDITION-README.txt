MF StaffCore - Free edition build
=================================

Version: 0.1.13
Edition: free (MF_STAFFCORE_EDITION=free)

Install on another WordPress site
---------------------------------
1. Copy this entire folder to: wp-content/plugins/mf-staffcore
2. Activate MF StaffCore Lite in Plugins.
3. Requires PHP 8.1+ and WordPress 6.0+.

Free limits
-----------
- No: Biometric, Documents (PDF), Awards, KPI/Performance, Backup/Restore
  (these are additional Pro-only modules)
- No employee cap and no locked built-in features. Everything else -
  Employees, Bulk link users, Payroll, Assets, Attendance, Leave,
  Frontend panel, and the full HR core - is fully functional in Lite.
